# 充電logger v0.2（試作版）

[English（正本）](CHARGING-LOGGER.md) · [日本語](CHARGING-LOGGER.ja.md)

キャプチャと排他のビルドです。`--features charging-logger` を指定すると、
画像保存／BMP出力を電圧・電流の記録／CSV出力に置き換えます。
通常ビルドは従来のキャプチャ版です。logger版のRelease配布ファイルは未公開です。

## 操作

1. 通常起動後、左右を約0.5秒同時押しして記録を開始します。
   `LOGGER REC 5s - L+R STOP` が記録中の表示です。同じ操作で停止します。
2. 校正済み電圧（mV）、符号付き電流（mA）、セッション番号、開始からの経過時間（ms）を
   約5秒間隔で保存します。区間平均ではなく、その時点の測定値です。
   読み取り失敗時は保存を飛ばすため、時刻の間隔が広がります。
3. 測定を終えて接続機器を外し、左右を押しながらPCの5 V USBに接続します。
   読み取り専用の `KWS LOGGER` ドライブから `LOG00001.CSV`～`LOG00006.CSV` をコピーします。
4. 消去する場合は、左右＋Backを押しながら5 Vで起動し、
   `ERASE LOGS+CAPTURES?` で全ボタンを離してからOKを2秒長押しします。
   Backでキャンセルできます。完了後は抜き差しして再起動してください。

**v0.2の消去は、保存用6区画内の既知のキャプチャも対象です。**
必要な画像は、先にキャプチャ版で取り出してください。logger版ではBMPを出力しません。
未知のデータは消しません。空きができなかった場合は `NO SPACE - UNKNOWN DATA` と表示します。

## 保存容量とCSV

- 保存先は `0x62000–0x6DFFF` の8 KiB×6区画だけです。
  工場データ・設定・ENERGY MEMORY（`0x78000`／`0x7A000`）はloggerの割り当て・消去対象外です。
- 各区画は16バイトのヘッダーと511サンプルを格納します。
  48 KiBすべて空きなら3,066サンプル、5秒間隔で約4時間15分です。
- 記録を開始するたびに新しいセッションと空き区画を使用します。
  停止したセッションの未使用部分は再利用しません。短い記録を繰り返すと早く満杯になります。
- 満杯や書き込み失敗で記録を停止します。記録中の自動消去・上書きはありません。
  再起動後は停止状態です。
- 1ファイルは1物理区画です。長いセッションは複数ファイルに分かれます。
  結合時はヘッダーを1つにして `session,elapsed_ms` 順に並べます。
  ファイル番号はセッション番号ではありません。

CSVはUSB読み出し時に生成します。本体には16バイトのコンパクトな記録を保存し、
チェックサムを最後に書き込みます。未完了・破損レコードは出力しません。
ヘッダー書き込みや消去の途中で電源が切れると、未知の区画として保持され、
通常の消去では回復できない場合があります。

## ビルド・書き込み・検証状況

```powershell
cargo test -p firmware-core --lib --locked --offline
cargo build -p firmware --release --target thumbv7em-none-eabihf --features charging-logger --locked --offline
```

依存関係を取得済みの環境向けのコマンドです。ビルドだけでは機器に書き込みません。
ローカル試作ファイルは `build/charging-logger-v0.2` にあります。
同じビルドのupper／mainとSHA256SUMSを使い、[書き込み手順](FLASHING.md)に従ってください。

38件のホストテスト、ARMビルド、X1C構造検査を通過しています。
KWS-X1 1台で書き込み、消去、約50秒の記録と電源を抜いた後のCSV取り出しを確認しました。
CY4500-EPRの記録には2回のREQUEST→ACCEPT→PS_RDYとそれぞれのGoodCRCがあり、
CSVの電圧変化と整合しています。両ログの時刻は同期していません。

**PDメッセージ自体はまだ記録しません。** フラッシュ書き込みは短時間割り込みを止めます。
今回の通信が書き込みの瞬間と重なった保証はなく、PDへの無影響を保証するものではありません。
長時間記録、書き込み／消去中の電源断、PD同時動作の厳密な検証は未完了です。
詳細は[検証記録（英語正本・日本語要約）](LOGGER-VALIDATION.md)を参照してください。
